# Data

This project uses public data from the **Building Data Genome Project 2**.

Repository:

```text
https://github.com/buds-lab/building-data-genome-project-2
```

Files used locally:

```text
data/raw/electricity.csv
data/raw/metadata.csv
data/raw/weather.csv
```

These files are not committed to GitHub because the electricity meter file is
large. The analysis code samples a small set of lodging/residential buildings
from the full public dataset so the project remains fast and easy to review.

The analysis is inspired by building performance intelligence use cases such as
energy monitoring, anomaly detection, out-of-hours waste checks and ESG-style
reporting. It does not use private Utopi data.
